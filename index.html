Reimagining Tool Configuration as Material with configCanvases

Angela Bi, Ritik Batra, Eric Rawn, Thijs Roumen

For non-computational art media such as pottery, physical painting, and woodworking, configuring tools is not an independent task necessary in order to make art; it is a complex, intertwined part of working with materials during the creative process. We explore how to make digital tool configuration more material for digital drawing software with configCanvas, an interface where users change digital brush parameters by adding colors onto a watercolor canvas. In a three-week study, we saw how experienced artists used configCanvases to negotiate intentions, develop new rhythms of working between tool and artwork, and generate histories of configuration.

Programming by Scaffolded Demonstration with Perpend

Angela Bi*, Eric Rawn*, Justin Lubin, Sarah Chasins

An important part of creative programming involves discovering what code should do in the first place. We built Perpend, a p5.js editor that displays the visual output of many possible modifications of the user’s program at a selected place in the program text, and found that helping creative programmers understand the possibilities around their program changed how they formed intentions for their program and visual outputs.
